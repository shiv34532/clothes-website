⚙️ Shipping & Delivery Fee Configurator

Configure delivery fees charged to customers during checkout. You can set a standard shipping charge, and optionally define a threshold above which delivery becomes completely free. Set the shipping charge to 0 to provide free shipping across all orders.

Enter 0 if you want standard shipping to be completely free by default.
Customers get free shipping if their order amount is equal to or greater than this limit. Set to 0 to keep shipping free on all items without a minimum order limit.

📍 Delivery PIN Code Management (Order Pincode Control)

Control which PIN codes or regions are allowed for placing orders on your store. You can specify state/city PIN prefixes (e.g. 38, 39), exact 6-digit PIN codes (e.g. 380001, 380002), or set to ALL for Pan-India delivery.

Enter 2-digit/3-digit prefixes or 6-digit PIN codes separated by commas or new lines. Type ALL or * to enable ordering for all PIN codes across India.
This message will be shown to customers on product pages and checkout if their PIN code is not allowed.
